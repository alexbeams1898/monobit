monobit · beep sandbox

Iterate on 1-bit sounds in real time. Same synthesis as the SDL/Arduboy runtime: 3-voice phase-accumulator XOR mixer (one pin, three voices' high-bits XOR'd), per-voice frequency stepped per "frame" (1/60 s). Two modes: SFX (single-voice classic beep tuner) and SOUND (1–3 voice patch — power chord, drum hit, melodic note — building blocks for songs).

Sound patch (1–3 voice, XOR mixer, engine-faithful)

A "patch" is a building block for songs — a single audio event using up to 3 voices XOR'd together. Mute the voices you don't need: a kick is V2-noise alone; a power chord is V0+V1+V2 tones; a chord- with-drum is all three with V2 in noise mode. Each voice is an independent Sfx (start freq, slope, duration). The mixer XORs the three voices' phase-accumulator high bits — the same algorithm the AVR ISR and SDL callback run.

Song (pattern grid)

A pattern is a 3-row grid: V0/V1/V2 across time. Each cell is one step (1/16 note at the song's BPM). Click a cell to drop a note (V0/V1) or drum (V2); right-click to clear. Press Play — the playhead walks left to right, looping if Loop is on. Edit while it's playing; changes apply on the next loop.
