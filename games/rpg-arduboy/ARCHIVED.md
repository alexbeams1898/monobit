# rpg-arduboy -- archived

The original Arduboy version of an action-RPG, imported from the `mono`
repo on 2026-05-05. Built on `engines/arduboy-legacy/`.

**Read-only reference.** Not part of monobit's CMake build. Do not extend
or modify code here.

The narrative IP from this game (Dantean cosmology, the Vagrant, Beatrice,
the Guide, the nine circles) lives on as **Selva Oscura** at
`games/selva-oscura/`, a 3D soulslike on the main engine.
