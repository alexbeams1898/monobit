# Cppcheck suppressions for monobit.
# Format: <check-id>:<file-pattern>[:<line>]
# ASCII only - non-ASCII characters break cppcheck's suppression parser.
# Note: cppcheck's --enable=all turns on unmatchedSuppression, so EVERY
# suppression listed here must actually match at least one finding or CI
# fails. Don't add speculative suppressions.

# FlowFieldSystem false positives.
# BfsItem fields consumed via structured binding; cppcheck only tracks
# direct .field access. Cross-function array reads through reference-to-
# array params are invisible to cppcheck's dataflow. DIRS iteration is
# already const-ref by intent; cppcheck wants pointer-syntax.
unusedStructMember:*FlowFieldSystem.cpp
unreadVariable:*FlowFieldSystem.cpp
constVariableReference:*FlowFieldSystem.cpp
